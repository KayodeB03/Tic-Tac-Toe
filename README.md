# Tic-Tac-Toe

# A simple Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Features

- Two-player gameplay
- Custom player names
- X and O markers
- Turn tracking
- Win and tie detection
- Restart game functionality
- Light and dark mode
- How to Play

- Enter the player names and take turns placing your marker on the game board. The first player to get three markers in a row wins. If the board fills up without a winner, the game ends in a tie.

## Technologies

- HTML
- CSS
- JavaScript
